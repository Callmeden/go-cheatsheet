# Библиотека курсов Дэна

## Основные (используем сейчас)

### 1. Leoscode — Самый полный курс Golang
- **Темы:** Основы, интерфейсы, ошибки, дженерики, конкурентность, работа с данными, веб, тестирование, микросервисы, безопасность.
- **Использование:** Основной источник теории.

### 2. Golang Ninja — Разработка Веб-Приложений на Go
- **Темы:** База, горутины, каналы, net/http, SQL, чистая архитектура, JWT, gRPC, Docker, CI/CD.
- **Использование:** Практика после Модуля 3.

### 3. Go: Антикурс без воды, до трудоустройства
- **Темы:** REST API, чистая архитектура, горутины, context, SQL, JWT, Marketplace (микросервисы), Docker, Prometheus.
- **Использование:** Глубокое погружение после веб-разработки.

### 4. SQL и PostgreSQL
- **Темы:** SELECT, JOIN, DDL, индексы, транзакции, триггеры, оконные функции.
- **Использование:** Параллельно с веб-разработкой (Фаза 2).

### 5. Алгоритмы и структуры данных
- **Темы:** Big O, сортировки, бинарный поиск, хэш-таблицы, графы, деревья, DP.
- **Использование:** Перед собеседованиями (Фаза 5).

## Дополнительные (справочники)

### 6. Go + Gin = Быстрый бекенд для заметок v2
- **Темы:** Микросервисы, Gin, PostgreSQL, MongoDB, Redis, Docker, Nginx, деплой.
- **Использование:** Быстрые рецепты по Gin/Docker.

### 7. Backend Master Class [Golang + Postgres + Kubernetes + gRPC]
- **Темы:** SQLC, миграции, Gin, JWT, Docker, AWS, Kubernetes, gRPC, Redis.
- **Использование:** Для роста до Junior+ (справочник).

### 8. Проектирование архитектуры и интеграций (API, брокеры) + ИИ
- **Темы:** REST, gRPC, SOAP, GraphQL, Kafka, RabbitMQ, БД, ИИ.
- **Использование:** Теория для собеседований (выборочно).

### 9. Основы брокеров сообщений (Kafka, RabbitMQ)
- **Темы:** Модели доставки, гарантии, Kafka, RabbitMQ.
- **Использование:** На вырост (после оффера).

### 10. ClickHouse с нуля
- **Темы:** OLAP, MergeTree, шардирование, аналитика.
- **Использование:** На вырост.
