# Мапы (Maps)

**Главное:** `map` — встроенный ассоциативный контейнер (key-value), реализован как **хэш-таблица**. Поиск/вставка/удаление — в среднем **O(1)**.

**Особенности в Go:**
- Ссылочный тип (копирование через `=` не копирует данные).
- Порядок итерации **не гарантируется**.
- **Не потокобезопасен.**

---

## Объявление и инициализация

**Объявление (nil-мапа):**
```go
var m map[string]int   // m == nil
```
⚠️ Nil-мапу можно читать, но нельзя в неё писать (см. подводные камни).

**Через `make` (рекомендуемый способ):**
```go
m := make(map[string]int)         // без указания ёмкости
m := make(map[string]int, 100)    // с начальной ёмкостью
```
Если знаешь примерный размер — указывай ёмкость: это избавит от лишних перераспределений памяти.

**Литерал:**
```go
fruits := map[string]int{
    "apple":  5,
    "banana": 3,
    "orange": 7,
}
```

**Требования к ключам — тип должен быть comparable:**
- ✅ `string`, `int`, `float64`, `bool`, структуры (если поля сравнимы).
- ❌ слайсы, функции, другие мапы.

**Значения** — любые типы (включая слайсы, мапы, структуры).

---

## Основные операции

| Операция | Синтаксис |
|---|---|
| Добавить / изменить | `m["key"] = 10` |
| Прочитать | `v := m["key"]` — zero value, если ключа нет |
| Проверить наличие | `v, ok := m["key"]` |
| Удалить | `delete(m, "key")` — если ключа нет, ничего не делает |
| Длина | `len(m)` |

**Проверка наличия ключа (comma-ok idiom):**
```go
value, exists := m["pear"]
if exists {
    fmt.Println("Значение:", value)
} else {
    fmt.Println("Ключ отсутствует")
}
```

## Итерация

```go
for key, value := range m { /* ... */ }

for key := range m       { /* только ключи */ }
for _, value := range m  { /* только значения */ }
```

⚠️ **Порядок итерации не гарантируется.** Если нужен предсказуемый вывод — сортируй ключи вручную:
```go
keys := make([]string, 0, len(m))
for k := range m {
    keys = append(keys, k)
}
sort.Strings(keys)
for _, k := range keys {
    fmt.Println(k, m[k])
}
```

**Удаление во время итерации безопасно.** `delete` внутри `range` — допустимо.

**Вложенные мапы** — через вложенные циклы `for range`:
```go
for category, items := range nestedMap {
    for item, quantity := range items { /* ... */ }
}
```

## Подводные камни

### 1. Nil-мапа vs make
```go
var m map[string]int
fmt.Println(m["x"])   // ✅ вернёт 0 (zero value)
m["x"] = 1            // 💥 panic: assignment to entry in nil map
```

| Операция | `make(...)` | `var m map[K]V` (nil) |
|---|---|---|
| Чтение `v := m[k]` | ✅ | ✅ (zero value) |
| Проверка `_, ok := m[k]` | ✅ | ✅ |
| Вставка `m[k] = v` | ✅ | ❌ panic |
| Удаление `delete(m, k)` | ✅ | ❌ panic |
| Итерация `for k, v := range m` | ✅ | ✅ (ничего не выполнится) |
| `len(m)` | ✅ | ✅ = 0 |

### 2. Порядок итерации не гарантирован
Причина — хэширование. См. раздел «Итерация» — сортируй ключи, если нужен порядок.

### 3. Не потокобезопасна
Одновременная запись из нескольких горутин → гонка данных → паника. Для конкурентного доступа есть `sync.Map`, но он для специфических сценариев. Подробно — в разделе про горутины.

### 4. Нельзя сравнивать напрямую
```go
m1 == m2   // ❌ ошибка компиляции
m == nil   // ✅ только проверка на nil
```
Для сравнения по содержимому — вручную или через `maps.Equal`.

### 5. Копирование через `=` — это НЕ копия
```go
copyMap := originalMap   // обе переменные указывают на одну и ту же мапу
```
Изменения видны через обе. Для настоящей копии — вручную или через `maps.Clone`.

## Set через `map[T]struct{}`

Когда нужен только факт наличия ключа — используй `map[T]struct{}`. Пустая структура занимает **0 байт** (оптимизируется компилятором).

```go
words := []string{"go", "rust", "go", "python"}
unique := make(map[string]struct{})

for _, w := range words {
    unique[w] = struct{}{}
}

if _, exists := unique["go"]; exists {
    fmt.Println("слово уже встречалось")
}

delete(unique, "rust")
```

Применяется для: множеств, visited-таблиц в графах, фильтров «уже обработано».

## Пакет `maps` (Go 1.21+)

```go
import "maps"

maps.Equal(m1, m2)     // сравнение по содержимому (bool)
clone := maps.Clone(m) // независимая копия
```

## Запомнить

- `map` — хэш-таблица, доступ в среднем за O(1).
- Ключи — только **comparable** типы (не слайсы, не функции, не мапы).
- Nil-мапа: **чтение работает, запись и `delete` → паника.**
- Порядка итерации нет — сортируй ключи вручную.
- `map` — ссылочный тип, `=` не копирует.
- Сравнивать через `==` нельзя (только с `nil`).
- Не потокобезопасна — для конкурентности есть `sync.Map`.
- `map[T]struct{}` — идиома для set.
- `maps.Equal`, `maps.Clone` — с Go 1.21.
