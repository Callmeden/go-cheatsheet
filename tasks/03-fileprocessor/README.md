## 📘 Домашнее задание: Обработка ошибок в файлообработчике

### Задача:

Реализовать функцию `ProcessFiles(paths []string) (int, error)`, которая принимает список путей к файлам и должна:

1. Открыть каждый файл
2. Прочитать его содержимое
3. Посчитать количество строк
4. Закрыть файл

Если при открытии, чтении или закрытии произошли ошибки — они **не должны теряться**.

Функция должна возвращать:

* `nil`, если все файлы успешно обработаны
* одну ошибку, если только один файл вызвал ошибку
* объединённую ошибку через `errors.Join`, если несколько ошибок

Также необходимо реализовать свою ошибку `FileError`, которая будет содержать:

* путь к файлу
* оригинальную ошибку
* метод `Error()` с сообщением вида: `ошибка с файлом {имя файла}: {текст ошибки}`
