# Задание 1: Парсер логических выражений

## Условие

Написать программу, которая способна **вычислять логические выражения**.

Выражения **чувствительны к регистру** и могут содержать:

### Знаки операций
| Операция | Смысл |
|---|---|
| `and` | И |
| `or` | Или |
| `not` | Отрицание |
| `xor` | Сложение по модулю 2 |

### Другое
- Скобки: `(`, `)`
- Логические значения: `True`, `False`
- **Пустое выражение имеет значение `False`**

## Требования

### 1. Переменные
- Имена переменных — **только маленькие буквы латинского алфавита** (например, `x`).
- Формат объявления: `<имя>=<True|False>;`
- **Пробелы допустимы.**
- Если переменная объявлена **несколько раз** — учитывается **последнее** значение.

### 2. Ограничения
- Все переменные, используемые в выражении, должны быть **заданы заранее**.
- **Запрещены имена**, совпадающие с ключевыми словами (`and`, `or`, `not`, `xor`).

### 3. Приоритеты операций
Учитываются стандартные приоритеты. **Пробелы не влияют** на разбор.

### 4. Обработка ошибок
Если выражение или объявление **не удовлетворяют** описанным правилам — вывести в стандартный поток вывода:

```
[error]
```

(без кавычек)

## Что изучил

- Токенизация строк
- Рекурсивный спуск (recursive descent)
- Приоритеты операторов
- Валидация входных данных
- Работа с ошибками через собственный тип
