# Задание 2: TypeBox — универсальное хранилище

## Условие

Реализовать мини-БД **TypeBox**, которая хранит значения разных типов под строковыми ключами и выполняет команды, читаемые из **STDIN**. Результаты некоторых команд выводятся в **STDOUT**.

### Обязательные требования к архитектуре
- Интерфейс `Printable` с методом `ToString() string`.
- Структуры `ObjectValue` и `ListValue`, реализующие `Printable`.
- Структура `TypeBox` — «объект БД» с методами.
- **Запрещено** использовать дженерики и пакет `encoding/json`.
- Числа с плавающей точкой выводить через `strconv.FormatFloat(v, 'f', -1, 64)`.

## Поддерживаемые данные

| Тип | Хранение |
|---|---|
| `int` | целое число |
| `float64` | число с плавающей точкой |
| `string` | строка |
| `ObjectValue` | обёртка над `map[string]interface{}` |
| `ListValue` | обёртка над `[]interface{}` |

Все значения лежат в одном общем `map[string]interface{}` внутри `TypeBox`.

## Формат ввода

Первая строка — **Q** (количество команд, 1 ≤ Q ≤ 1000). Далее — Q строк с командами.

### 1. SET — скалярное значение

```
SET key TYPE value
```

- `key` — строка без пробелов.
- `TYPE ∈ {INT, FLOAT, STRING}`.
- `value` — значение соответствующего типа.

**Примеры:**
```
SET age INT 25
SET pi FLOAT 3.14
SET name STRING Alice
```

### 2. OBJECT — создание объекта

```
OBJECT key n
field1 TYPE1 value1
field2 TYPE2 value2
...
fieldN TYPEN valueN
```

- `key` — имя объекта.
- `n` — количество полей (1 ≤ n ≤ 20).
- Далее **n строк** формата `fieldName TYPE value`.
- Поля могут быть `INT`, `FLOAT`, `STRING`.

### 3. PUSH — добавить в список

```
PUSH key TYPE value
```

- Если по `key` **нет значения** — создать новый список с одним элементом.
- Если по `key` **уже список** (`ListValue`) — дописать значение в конец.
- Если по `key` **не список** — создать новый список, положить **старое значение**, затем **новое**, сохранить как `ListValue`.

### 4. MERGE — слияние объектов

```
MERGE target source
```

- Оба ключа должны содержать `ObjectValue`.
- Поля из `source` копируются в `target`.
- При совпадении имён — значение из `source` **перезаписывает** значение в `target`.
- Если хотя бы один ключ не объект — **команда игнорируется**.

### 5. PRINT — вывод значения

```
PRINT key
```

Формат вывода:
- `INT` → просто число (`42`).
- `FLOAT` → через `strconv.FormatFloat(v, 'f', -1, 64)` (`3.14`, `2`, `2.5`).
- `STRING` → без кавычек (`Hello`).
- `ListValue` → `[v1,v2,v3]` без пробелов.
- `ObjectValue` → `{key1:val1,key2:val2}` — **ключи отсортированы** лексикографически, без пробелов.
- Внутри списков и объектов — **рекурсивное** форматирование.
- Если ключа нет — вывести `null`.

## Пример

**Ввод:**
```
11
SET age INT 25
SET name STRING Alice
OBJECT person 2
age INT 30
city STRING London
PUSH list INT 10
PUSH list STRING hello
PUSH list FLOAT 3.5
MERGE person_extra person
PRINT age
PRINT list
PRINT person
PRINT unknown
```

**Вывод:**
```
25
[10,hello,3.5]
{age:30,city:London}
null
```

## Что изучил

- Интерфейс `Printable` и **полиморфизм** через `interface{}`.
- **Type assertion** и `type switch` для распаковки `interface{}`.
- **Рекурсивное форматирование** — `ObjectValue` и `ListValue` могут содержать друг друга.
- **Композиция через embedding** — `ObjectValue` и `ListValue` внутри `interface{}`.
- Парсинг **многострочного ввода** через `bufio.Scanner`.
- Работа с **map + sort** для детерминированного вывода.
- `strconv` — парсинг и форматирование чисел.
- `strings.Builder` для эффективной сборки строк.
- `maps.Copy` — копирование map (Go 1.21+).
- Разница **pointer vs value receiver** в контексте интерфейсов.

## Заметки

- **`PUSH` поверх скаляра** — оборачивает старое значение + новое в новый `ListValue`.
- **`MERGE` игнорирует** любые не-объекты — тихо, без ошибок.
- **Сортировка ключей** объекта обязательна — иначе вывод недетерминированный.
- **`FormatFloat(v, 'f', -1, 64)`** — `2.0` → `"2"`, `2.5` → `"2.5"`. `%v` такой результат не гарантирует.
