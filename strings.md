## Строки, байты и руны

**Главное:** Строка в Go — это **неизменяемая** (immutable) последовательность **байтов** в кодировке UTF-8.

**Кодировки (кратко):**
- **ASCII** — 1 байт, только латиница и цифры (0–127).
- **Unicode** — таблица всех символов мира (кодовая точка, например `U+042F`).
- **UTF-8** — способ хранения Unicode в байтах. Переменная длина:
  - Латиница → 1 байт.
  - Кириллица → 2 байта.
  - Эмодзи → 4 байта.

**Три способа работы с текстом:**

| Тип | Размер элемента | Изменяемый? | Когда использовать |
|-----|-----------------|-------------|---------------------|
| `string` | Зависит от UTF-8 | Нет | Тексты, поиск, сравнение |
| `[]byte` | 1 байт | Да | Низкоуровневая работа, сеть, файлы |
| `[]rune` | 4 байта (int32) | Да | Unicode, эмодзи, подсчет символов |

**Иммутабельность:**
```go
str := "hello"
// str[0] = 'H' // ОШИБКА компиляции
newStr := "H" + str[1:] // создаем новую строку
```

**Длина строки:**
- `len(str)` — количество **байтов** (не символов!).
- `utf8.RuneCountInString(str)` — количество **символов** (рун).

Пример:
```go
str := "Go💻"
len(str)                      // 6 (байтов)
utf8.RuneCountInString(str)   // 3 (символа)
```

**Преобразования:**
- `[]byte(str)` — строка в байты (создает копию).
- `string(bytes)` — байты в строку (создает копию).
- `[]rune(str)` — строка в руны (создает копию).
- `string(runes)` — руны в строку.

**Перебор строки:**
- `for i := 0; i < len(s); i++` — идет по **байтам** (осторожно с Unicode!).
- `for i, r := range s` — идет по **рунам** (правильно для Unicode).

## Основные операции со строками

**1. Конкатенация:**
- `str1 + " " + str2` — просто, но каждый раз создает новую строку.
- `strings.Builder` — эффективно для циклов и длинных строк:
  ```go
  var b strings.Builder
  b.WriteString("Hello")
  b.WriteString(" ")
  b.WriteString("World")
  result := b.String()
  ```

**2. Извлечение подстроки:**
- `str[start:end]` — работает **по байтам**, не по символам!
- Осторожно с Unicode: может "порвать" символ.
- Для работы с символами: `[]rune(str)` → срез → `string(...)`.

**3. Индексация:**
- `str[0]` — возвращает **байт** (тип `byte`/`uint8`).
- Для доступа к символу: `[]rune(str)[i]`.

**4. Преобразования:**
- `[]byte(str)` — строка в байты (копия).
- `string(bytes)` — байты в строку (копия).

**5. Сравнение:**
- Операторы: `==`, `<`, `>`, `<=`, `>=` (лексикографически).
- `cmp.Compare(a, b)` — возвращает `-1`, `0`, `1`.

**6. Итерация:**
- **По байтам:** `for i := 0; i < len(s); i++ { s[i] }`.
- **По рунам:** `for i, r := range s { ... }` — безопасно для Unicode.
  - `i` — байт-индекс начала руны.
  - `r` — руна (int32).

**Запомнить:** `range` по строке декодирует UTF-8 и дает тебе руны. Это правильный способ обхода текста.

## Пакет `strings` — основные функции

**Поиск:**
- `strings.Contains(s, sub)` — содержит ли подстроку (bool).
- `strings.Index(s, sub)` — индекс первого вхождения (`-1`, если нет).
- `strings.LastIndex(s, sub)` — индекс последнего вхождения.
- `strings.HasPrefix(s, prefix)` — начинается ли с.
- `strings.HasSuffix(s, suffix)` — заканчивается ли на.

**Регистр:**
- `strings.ToUpper(s)` — в верхний регистр.
- `strings.ToLower(s)` — в нижний регистр.

**Обрезка:**
- `strings.Trim(s, cutset)` — удалить указанные символы с начала и конца.
- `strings.TrimSpace(s)` — удалить пробелы с начала и конца.

**Замена:**
- `strings.Replace(s, old, new, n)` — заменить `n` вхождений.
- `strings.ReplaceAll(s, old, new)` — заменить все вхождения.

**Разделение и соединение:**
- `strings.Split(s, sep)` — разбить строку по разделителю (возвращает `[]string`).
- `strings.Join(slice, sep)` — соединить слайс строк в одну.
- `strings.Fields(s)` — разбить по пробельным символам (пробелы, табы, переносы).
- `strings.FieldsFunc(s, func)` — разбить по условию.

**Повторение:**
- `strings.Repeat(s, n)` — повторить строку `n` раз.

**Эффективная конкатенация:**
- `strings.Builder` — для сборки длинных строк в циклах.

**Совет:** Если операция есть в `strings`, используй её, а не пиши цикл руками.

## Пакет `strconv` — преобразование типов

**Число → Строка:**
- `strconv.Itoa(n)` — int в строку (сокращение от "integer to ASCII").
- `strconv.FormatInt(n, base)` — int64 в строку в заданной системе счисления (2–36).
- `strconv.FormatFloat(n, fmt, prec, bits)` — float64 в строку.
  - `fmt`: `'f'` (фиксированный), `'e'` (экспонента), `'g'` (кратчайший).
  - `prec`: количество знаков после запятой (-1 = автоматически).
- `strconv.FormatBool(b)` — bool в строку.

**Строка → Число:**
- `strconv.Atoi(s)` — строка в int. Возвращает `(int, error)`.
- `strconv.ParseInt(s, base, bits)` — строка в int64.
- `strconv.ParseFloat(s, bits)` — строка в float64.
- `strconv.ParseBool(s)` — строка в bool.

**ParseBool принимает:**
- `true`: `"1"`, `"t"`, `"T"`, `"true"`, `"TRUE"`.
- `false`: `"0"`, `"f"`, `"F"`, `"false"`, `"FALSE"`.

**Важно:** Все функции парсинга возвращают ошибку вторым значением. Всегда проверяй:
```go
num, err := strconv.Atoi("42")
if err != nil {
    // обработать ошибку
}
```

**Запомни:** `strconv` — это мост между строкой и другими типами. Без него не обходится парсинг JSON, конфигов и пользовательского ввода.

## Пакет `regexp` — регулярные выражения

**Создание:**
- `regexp.Compile(pattern)` — возвращает `(*Regexp, error)`. Используй, если паттерн может быть невалидным.
- `regexp.MustCompile(pattern)` — паникует при ошибке. Используй для проверенных паттернов.

**Основные методы:**
- `re.MatchString(s)` — соответствует ли строка паттерну (bool).
- `re.FindString(s)` — первое совпадение.
- `re.FindAllString(s, n)` — все совпадения (`n = -1` — все).
- `re.ReplaceAllString(s, repl)` — заменить все совпадения.

**Сырые строки (raw strings):**
- Используй обратные апострофы для упрощения: `` `\d+` `` вместо `"\\d+"`.

**Unicode:**
- `\p{L}` — буквы, `\p{N}` — цифры.
- Пример: `` `\p{L}+` `` находит слова на любом языке.

**Лучшие практики:**
- Компилируй regexp один раз и переиспользуй.
- Не злоупотребляй сложными паттернами.
- Тестируй на regex101.com.
- Документируй сложные выражения комментариями.

**Когда использовать:**
- Парсинг логов, валидация email/телефона, извлечение данных из текста.
