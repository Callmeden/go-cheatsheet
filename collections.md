## Массивы (Arrays)

**Главное:** Фиксированный размер. Длина не меняется.

**Особенность Go:** Длина входит в тип.
`[4]int` и `[5]int` — это **разные типы**. Присвоить один другому нельзя.

**Создание:**
- `var arr [3]int` — через var.
- `arr := [3]int{1, 2, 3}` — с указанием длины.
- `arr := [...]int{1, 2, 3}` — длина определяется автоматически.
- Частичная инициализация: `arr := [5]int{1, 4: 5}` // `[1 0 0 0 5]`.

**Многомерные:**
`matrix := [2][2]int{{1, 2}, {3, 4}}`

**Операции:**
- `len(arr)` и `cap(arr)` — для массива возвращают одно и то же (его длину).
- Итерация:
  ```go
  for i := 0; i < len(arr); i++ { ... } // по индексу
  for index, value := range arr { ... } // по значению (value — копия!)
  ```

**Ключевые нюансы:**
1. **Передача в функцию:** Массив передается **по значению** (копируется). Изменения внутри функции не влияют на оригинал. Чтобы изменить оригинал, нужно передать указатель: `func f(arr *[3]int)`.
2. **Выход за границы:** Обращение к несуществующему индексу вызывает `panic: index out of range`.
3. **Когда использовать:** Когда размер известен заранее, нужна производительность или работа с низкоуровневыми данными (байты, шифрование).

**Память:** Элементы лежат в памяти подряд. Адрес массива == адрес первого элемента.
- **Стек (Stack):** Быстрая память для локальных переменных. Работает по LIFO. Данные автоматически удаляются, когда функция завершилась.
- **Куча (Heap):** "Склад" для данных, которые должны жить дольше, чем функция (например, если на них ссылаются извне). Управляется Сборщиком Мусора (Garbage Collector).

## Слайсы (Slices)

**Что это:** Динамический массив. В основе лежит обычный массив.

**Структура слайса (3 поля):**
- Указатель на массив (данные).
- `len` — длина (текущее количество элементов).
- `cap` — ёмкость (сколько памяти выделено).

**Создание:**
- `var s []int` — nil-слайс (`nil` — нулевое значение).
- `s := []int{1, 2, 3}` — литерал.
- `s := make([]int, 3, 5)` — длина 3, ёмкость 5 (заполнен нулями).

**Взятие среза (slicing):**
`b := a[1:3]` — элементы с индекса 1 до 2 (конец НЕ включен).
- По умолчанию: `a[:3]` (от 0), `a[1:]` (до конца).
- Новая длина: `end - start`.
- Новая ёмкость: `cap(исходного) - start`.

**ВАЖНО:** Срез **не копирует** данные, а ссылается на тот же массив.
Изменение через срез меняет оригинальный массив.

**Копирование:**
- Простое присваивание (`s2 := s1`) не копирует данные.
- Для создания независимой копии:
  ```go
  s2 := make([]int, len(s1))
  copy(s2, s1) // копирует в s2
  ```

**Добавление элементов (`append`):**
- `s = append(s, 4)` — добавить один.
- `s = append(s, 4, 5, 6)` — добавить несколько.
- `s = append(s, other...)` — добавить другой слайс.
- **Правило:** Всегда присваивать результат `append` обратно (`s = append(s, ...)`).
- Если `cap` не хватает, выделяется **новый массив** (обычно в 2 раза больше), данные копируются.

**Удаление элемента (через append):**
`s = append(s[:i], s[i+1:]...)` — удалить элемент с индексом `i`.

**Передача в функцию:**
Слайс передается **по значению**, но так как внутри есть указатель:
- Изменение **элементов** внутри функции меняет оригинал.
- Изменение **длины** (через `append`) не меняет оригинал.
- Чтобы изменить длину, нужно возвращать новый слайс: `func f(s []int) []int`.

**Сравнение Массив vs Слайс:**
- Массив: размер фиксирован, передается по значению.
- Слайс: размер динамический, ссылается на массив.

**Важно: подводные камни `append`**

- Если `cap` хватает, `append` пишет в тот же массив → другие слайсы могут измениться.
- Если `cap` не хватает, `append` выделяет новый массив → слайсы становятся независимыми.

**Классическая задача:**
```go
x := []int{}
x = append(x, 0, 1, 2) // len=3, cap=4
y := append(x, 3)      // массив [0,1,2,3], y видит 4 элемента
z := append(x, 4)      // массив [0,1,2,4], y и z видят [0,1,2,4]
fmt.Println(y, z)      // [0 1 2 4] [0 1 2 4]
```
Чтобы избежать сюрпризов, используй `copy` или полную форму среза `x[:len(x):len(x)]` для ограничения `cap`.

## Пакет `slices` (Go 1.21+)

**Зачем:** Заменяет ручные циклы для типовых операций над слайсами.

**Импорт:** `import "slices"`

**Основные функции:**
- `slices.Contains(slice, val)` — проверка наличия элемента (bool).
- `slices.ContainsFunc(slice, func)` — проверка по условию.
- `slices.Index(slice, val)` — индекс первого вхождения или `-1`.
- `slices.IndexFunc(slice, func)` — индекс по условию.
- `slices.Equal(a, b)` — сравнение двух слайсов (bool).
- `slices.Clone(slice)` — создать независимую копию.

**Сортировка:**
- `slices.Sort(nums)` — по возрастанию.
- `slices.SortFunc(nums, cmp.Compare)` — через функцию сравнения.
- `slices.SortFunc(nums, func(a, b int) int { return -cmp.Compare(a, b) })` — по убыванию.

**Проверка сортировки:**
- `slices.IsSorted(nums)` — отсортирован ли.
- `slices.IsSortedFunc(nums, cmp.Compare)` — с кастомным условием.

**Вставка и удаление:**
- `slices.Insert(slice, i, vals...)` — вставить элементы на позицию `i`.
- `slices.Delete(slice, i, j)` — удалить элементы с `i` до `j` (не включая `j`).

**Пакет `cmp` (для сравнения):**
- `cmp.Compare(a, b)` возвращает: `-1` (a < b), `0` (a == b), `1` (a > b).
- `cmp.Less(a, b)` возвращает `true`, если a<b.

**Важно про предикаты:**
- В `slices.SortFunc` функция принимает **элементы** `func(a, b T) int`.
- В `sort.Slice` функция принимает **индексы** `func(i, j int) bool`.
